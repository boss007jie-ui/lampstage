# Product understanding

Create a compact brief with:

- product name and category
- visible features and confirmed specifications
- target market, buyer and channel
- use cases and desired tone
- claims that are allowed, unknown or require confirmation

Use the source image for visible attributes only. Do not infer safety, certification, dimensions or performance from pixels. Pass the brief to downstream Skills as JSON-like fields so image, video and copy outputs stay consistent.

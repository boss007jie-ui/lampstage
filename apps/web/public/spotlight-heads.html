Lampstage 射灯光源造型

把现在的「纯圆点」换成有造型的射灯灯头。三个方向都接在同一束光锥 + 地面光斑上，背景配色与线上一致。挑一个，我落到工作台代码里。

方向 A · 轨道筒灯
Track spotlight
方形筒灯头 + 短支臂，像展厅/舞台轨道射灯。最"专业打光"，呼应产品定位。
LAMPSTAGE
方向 B · 吊挂筒灯
Pendant can
细线吊挂 + 锥形灯罩 + 灯泡口，本身就是一盏"灯具"，最贴合卖灯的主题。
LAMPSTAGE
方向 C · 极简光环
Minimal ring
一圈金环 + 中心发光核。最克制、最现代，不那么具象但精致。
LAMPSTAGE

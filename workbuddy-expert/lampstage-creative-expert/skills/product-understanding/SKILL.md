# Workflow understanding

Create a compact brief with:

- subject or asset name and category, when known
- visible features and confirmed specifications
- target audience, channel and intended outcome
- use cases and desired tone
- claims that are allowed, unknown or require confirmation

Use source assets for visible attributes only. Do not infer safety, certification, dimensions or performance from pixels. Pass the brief to downstream skills as JSON-like fields so API requests stay consistent.

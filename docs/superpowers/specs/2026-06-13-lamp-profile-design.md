- **作者**：Codex（结对设计）
- **日期**：2026-06-13
- **状态**：已与产品负责人逐节确认，待写实现计划
- **关联代码**：`apps/web/lib/generation.ts`、`apps/web/lib/lamp-detect.ts`、`apps/web/lib/suggest-scenes.ts`、`apps/web/app/workspace/page.tsx`

## 0. 一句话定位

把现在"AI 瞎猜"的灯具场景图生成，升级为**"AI 先猜 + 用户修正 + 行业规范注入"**的专业流程：上传后 AI 一次推断灯具的尺寸/色温/目标客群等核心维度，用户 10 秒确认/修改，后端自动按行业规范生成 3 张比例正确、风格命中的家居场景图。

## 1. 背景与动机

### 1.1 现状短板

当前生成流程在以下"专业维度"完全缺失：

| 维度 | 现状 | 后果 |
|---|---|---|
| **灯具尺寸**（直径/高度） | 完全不收集 | 吊灯比餐桌还大、台灯顶天立地 |
| **灯泡色温** | 完全不收集 | 暖光产品被画成冷白光，与卖点矛盾 |
| **是否点亮** | 默认关灯 | 氛围灯卖的就是开灯感，没体现 |
| **风格/目标客群** | 4 张图随机 4 种 | 命中率不到 25%，浪费额度 |
| **行业规范** | 不注入 prompt | 吊灯距餐桌距离、壁灯安装高度等 AI 不懂 |

### 1.2 用户画像

灯具卖家（精装房、独立站、店群、工厂代运营），对**专业感**敏感（一眼能看出比例不对、色温不符），但对**填表门槛**也敏感（多 30 秒就嫌烦）。本方案在二者之间取平衡。

### 1.3 商业目标

- **专业度**：出图比例对、风格对、色温对，可直接上架不用二次修图
- **效率**：用户感知耗时降 30%（从 75s → 55s），AI 推断 3-5 秒看到结果
- **成本**：单次生成成本从 ¥0.62 降至 ¥0.46（少 1 张图、推断比智能推荐便宜），毛利率从 35% → 50%

## 2. 用户体验流程

### 2.1 改造前 vs 改造后

```
现状：
上传 → 选模式（智能推荐/快捷模板/自由描述）→ 选风格 → 选比例 → 等 25s → 选场景 → 生成
       ↑ AI 啥都不知道，瞎猜

新版：
上传 → 等 3-5s AI 识别 → 用户确认 4 个参数 → 选比例 → 生成
       ↑ AI 给默认值，用户改不对的
```

### 2.2 详细步骤

**Step 1：上传灯具图**（保留现有 UI）

**Step 2：AI 识别 + 参数确认**（核心新增）

上传后 2-3 秒内，工作台中间出现**「灯具档案」卡片**，AI 已预填所有字段，用户扫一眼直接生成。如有不对再改。

```
┌────────── AI 识别结果 ──────────────┐
│                                      │
│ 类型：吊灯（pendant）                │
│                                      │
│ 尺寸：● 中（30-60cm）  ○ 小  ○ 大    │
│       ↑ AI 默认勾，用户可改          │
│                                      │
│ 色温：● 暖光 3000K  ○ 中性 4000K     │
│       ○ 冷白 5500K  ○ 多档可调       │
│       ↑ AI 默认勾，用户可改          │
│                                      │
│ 目标客群：● 现代轻奢  ▼              │
│   北欧极简/侘寂日式/工业 LOFT/       │
│   新中式/法式优雅                    │
│                                      │
│ ───────────────────────              │
│                                      │
│ 比例：● 1:1 主图  ○ 4:5  ○ 16:9      │
│                                      │
│ [生成 3 张预览图]                    │
└──────────────────────────────────────┘

▼ 高级选项（旧 Tab，藏在折叠面板）
  - 快捷模板
  - 自由描述
```

**Step 3：生成中**——保留现有 5 阶段进度时间线

**Step 4：3 张图轮播展示**——保留现有 UI

### 2.3 关键变化点

1. **去掉"智能推荐 / 快捷模板 / 自由描述"主 Tab**，并到一张档案卡里
2. **保留旧 Tab 作为高级选项**藏在折叠面板，1-2 周稳定后删除
3. **核心交互浓缩到一张卡片**——不再 4 个分散步骤

## 3. 3 张图的内容自动决定

确认参数后，后端**自动**决定 3 张图的具体内容，不让用户挑。

### 3.1 房间组合（按灯具类型固定）

| 灯具类型 | 3 张图房间组合 |
|---|---|
| 吊灯 pendant | 餐厅 / 客厅 / 玄关 |
| 吸顶灯 ceiling | 客厅 / 卧室 / 书房 |
| 壁灯 wall | 卧室床头 / 走廊 / 客厅背景 |
| 台灯 table | 卧室床头柜 / 书桌 / 客厅边几 |
| 落地灯 floor | 客厅角落 / 阅读区 / 卧室角落 |

### 3.2 开关灯分配

按行业惯例：

- **吊灯 / 吸顶灯**：1 张关灯展示造型（白天自然光） + 2 张开灯氛围（傍晚 / 夜晚）
- **氛围灯类**（壁灯 / 台灯 / 落地灯）：2 张开灯 + 1 张关灯
- **色温多档可调**：3 张里至少 1 张展示不同色温对比（暖光晚餐 vs 冷白阅读）

### 3.3 比例适配

| 比例 | 构图特点 |
|---|---|
| 1:1 主图 | 灯具占画面 40-50%（电商主图标准） |
| 4:5 详情 | 灯具 + 周围 1m 范围（详情页中段） |
| 16:9 横图 | 完整房间布局（场景图 / banner） |

### 3.4 行业规范注入 prompt（写死，不可配置）

```
吊灯：下沿距餐桌 70-90cm，直径 ≈ 餐桌宽度 1/2-1/3
壁灯：距地面 1.4-1.6m（卧室床头）/ 1.6-1.8m（走廊）
台灯：高度 ≈ 桌面高度 + 35-50cm
落地灯：高度 1.5-1.8m，距沙发 30-50cm
吸顶灯：层高 ≥2.7m 时合适
```

后端拼 prompt 时自动注入这些规范，AI 出图自然遵守，**用户不需要看到**。

## 4. 实现架构

### 4.1 数据库改动

`UploadedAsset` 表新增 4 个字段：

```prisma
model UploadedAsset {
  // ... 现有字段保留 ...

  // 新增：灯具档案（AI 推断 + 用户确认）
  size_class       String?   // "small" | "medium" | "large"
  color_temp       String?   // "warm_3000k" | "neutral_4000k" | "cool_5000k" | "tunable"
  target_audience  String?   // 6 个客群之一
  ai_inferred_at   DateTime? // AI 识别完成时间
}
```

`lamp_type` 字段已存在（`LampType` enum），复用。

**为什么放 UploadedAsset 不放 GenerationJob**：同一张灯具图可生成多次（用户改风格再生），档案应跟"灯具"绑定，不跟"任务"绑定。

### 4.2 新增模块：`lib/lamp-profile.ts`

负责"AI 一次推断所有维度 + 写库"。一次调用 vision 模型（gpt-5-mini，跟 suggest-scenes 同款），让它返回结构化 JSON：

```typescript
{
  lamp_type: "pendant",
  size_class: "medium",
  size_hint_cm: 45,           // AI 估算的具体数值（参考用，注入 prompt）
  color_temp: "warm_3000k",
  target_audience: "modern_luxury",
  material_keywords: ["黑金属", "亚麻灯罩"],
  reasoning: "Black metal frame + linen shade suggests modern luxury...",
}
```

### 4.3 改造模块：`lib/generation.ts`

新版 `buildPrompt(asset, sceneRoom, lit)`：从档案读维度、注入行业规范、决定开关灯。

新增 `decideThreeShots(asset)`：按灯具类型从 `ROOM_SETS` 挑 3 个房间 + `LIT_PATTERN` 决定开关灯，返回 3 个 prompt。

新增常量：

```typescript
const INDUSTRY_RULES: Record<LampType, string> = { ... };  // 行业规范
const ROOM_SETS: Record<LampType, [string, string, string]> = { ... };  // 房间组合
const LIT_PATTERN: Record<LampType, [boolean, boolean, boolean]> = { ... };  // 开关灯模式
const AUDIENCE_KEYWORDS: Record<string, string> = {  // 6 客群对应 prompt 关键词
  modern_luxury: "modern luxury, black metal + marble, leather, velvet",
  nordic: "nordic minimalist, light oak + white + linen",
  wabi_sabi: "wabi-sabi japanese, gray/white + raw wood + paper",
  industrial: "industrial loft, black iron + concrete + vintage brass",
  new_chinese: "new chinese style, solid wood + ink wash + greenery",
  french: "french elegant, ivory + arches + gold trim + florals",
};
```

### 4.4 新增 API

```
POST  /api/uploads/[id]/profile     // 触发 AI 推断（创建/刷新档案）
PATCH /api/uploads/[id]/profile     // 用户修改字段
```

### 4.5 改造 API

`POST /api/generation/jobs`：

- 简化 input：不再要求 sceneKind / templateId / customPrompt（**新流程不传**）
- 内部 fork：
  - 如果带了 sceneKind → 走旧逻辑（兼容老路径）
  - 否则 → 读 asset profile，调用 `decideThreeShots(asset)` 生成 3 张

### 4.6 前端

新建 `components/workspace/LampProfileCard.tsx`：
- 接 AI 推断结果，渲染 4 个字段可改 UI
- 字段改动 → PATCH 同步 DB
- "生成 3 张"按钮触发新流程

改造 `app/workspace/page.tsx`：
- 上传完 → POST `/api/uploads/[id]/profile` 触发推断（异步）
- 推断完 → 渲染 LampProfileCard
- 旧 SceneSelector 三 Tab UI → 折叠到"高级选项"
- 加风格冲突警告（小字提示，不阻拦）

### 4.7 Feature Flag（回滚保险）

新增环境变量：

```
NEW_LAMP_FLOW_ENABLED=*** false
```

代码里：

```tsx
{process.env.NEW_LAMP_FLOW_ENABLED === "true" ? (
  <LampProfileCard ... />     // 新流程
) : (
  <SceneSelector ... />       // 旧流程（保留）
)}
```

**作用**：上线后 2 分钟可随时切回旧版（改环境变量 + 重新部署），零代码改动。1-2 周稳定后再删旧代码。

## 5. 成本、性能、降级

### 5.1 单次生成成本（预估）

| 步骤 | 模型 | 调用次数 | 单次成本（¥） |
|---|---|---|---|
| AI 推断档案 | gpt-5-mini (vision) | 1 次/上传 | ~0.01 |
| 生图 | nano-banana | 3 次/生成 | 0.45 |
| **总计** | | | **~0.46/单** |

对比现状（智能推荐 ¥0.02 + 4 张生图 ¥0.60 = ¥0.62）：**降本 26%**。
按 ¥0.30/张定价，**毛利率从 35% → 50%**。

### 5.2 用户感知耗时

| 阶段 | 现状 | 优化后 | 变化 |
|---|---|---|---|
| 上传到看到结果 | 25s（智能推荐） | **3-5s** | ⬇️ 80% |
| 选场景到生成完 | 30-50s | 30-50s | 不变 |
| 总时长 | 55-75s | **33-55s** | ⬇️ 30% |

### 5.3 降级方案

| 场景 | 处理 |
|---|---|
| AI 推断失败（网络/限额/超时） | 默认值：`unknown / medium / warm_3000k / modern_luxury`，卡片提示"AI 识别暂时不可用" |
| 推断超过 10 秒 | 同上，用默认值 |
| 单张图生成失败 | 保留另外 2 张，标记失败那张可重试，**只扣 2 次额度** |
| 全部生成失败 | 退回 3 次额度 |
| 风格冲突（识别 vs 用户选不同） | 不阻拦，按用户选的出图，仅小字提示 |

### 5.4 监控指标

| 指标 | 上线前 | 上线后目标 |
|---|---|---|
| 生成成功率 | ~85% | ≥90% |
| 用户改 AI 默认值的比例 | - | 看哪个字段最常改（推断准不准） |
| 目标客群分布 | - | 看哪 6 个最热门，下一版优化 |
| 平均生成耗时 | 75s | ≤55s |
| 用户复购率 | - | 比对旧 vs 新用户额度消耗速度 |

## 6. 实现里程碑

| 阶段 | 内容 | 工时 |
|---|---|---|
| 1. 数据库 + AI 推断 | schema 加字段 + migrate；新建 lamp-profile.ts；POST/PATCH `/api/uploads/[id]/profile` | 3h |
| 2. 智能 prompt 拼接 | 改 buildPrompt + 新增 decideThreeShots；写 ROOM_SETS / LIT_PATTERN / INDUSTRY_RULES / AUDIENCE_KEYWORDS；改造 jobs API（兼容旧路径） | 2h |

**共计 9 小时（约 1 个工作日），一口气做完。**

部署节奏：阶段 1+2 部署后端（不影响现有用户），阶段 3+4 部署前端（含 Feature Flag）。**Feature Flag 默认 false 上线** → 你看一眼新版没问题 → 改 `=true` 启用 → 1-2 周稳定后删旧 Tab。

## 7. 风险与应对

| 风险 | 概率 | 应对 |
|---|---|---|
| AI 把"金色法式吊灯"推成"工业 LOFT" | 低 | 用户能 1 秒改回，不致命 |

## 8. 已锁定的取舍清单（设计阶段决策记录）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 维度采集策略 | B（AI 先猜 + 用户改） | 灯具卖家专业感强、愿意改，AI 全自动太碰运气 |
| 尺寸采集 | D（小/中/大 + 餐桌参照物 → AI 算出比例） | 小白也能填，AI 当室内设计顾问算行业搭配 |
| 色温采集 | A（AI 看图猜默认值，用户三选一改） | 暖光是市场主流，命中率高；色温是产品物理属性，必须照实填 |
| 开关灯 | X（按场景自动 1 关 2 开 或 2 开 1 关） | 卖家详情页正好用——主图关灯 + 氛围图开灯 |
| 目标客群 | B 单选 6 预设（轻奢/北欧/侘寂/工业/新中式/法式） | 灯具有目标客群，多选是伪需求；6 类覆盖 80% 市场 |
| 推断方式 | 一次 vision 调用全维度返回 | 减少调用次数 + 成本 |
| 旧 Tab UI | Feature Flag 兜底，立即默认切到新版 | 用户随时可切回，1-2 周稳定后删 |
| 风格冲突处理 | 仅提示不阻拦 | 用户控制权 > AI 判断 |
| 行业规范配置 | 写死在代码里 | MVP 阶段不需要管理后台改 |

## 9. 验收标准

部署完成后，用以下 5 个测试用例验收：

| 用例 | 输入 | 期望输出 |
|---|---|---|
| 1. 黑金吊灯 50cm | 上传图、用户不改任何字段 | AI 推荐"现代轻奢" → 3 张图分别为：餐厅（黑金黑桌轻奢）+ 客厅（关灯展示）+ 玄关（夜晚开灯氛围） |
| 2. 木质北欧吊灯 40cm | 上传后改"目标客群=北欧极简" | 3 张图为浅木+白色北欧调，色温暖白 3500K |
| 3. 床头壁灯 | 上传 | 3 张图为卧室床头 + 走廊 + 客厅背景，2 开 1 关 |
| 4. 台灯（高 60cm） | 上传 | 3 张图为床头柜 + 书桌 + 边几，台灯高度合理 |
| 5. 多档色温吊灯 | 上传 + 选"色温=多档可调" | 3 张里至少 1 张展示不同色温对比（暖白 vs 冷白） |

5 个用例**全部肉眼通过**才算上线成功。

## 10. 后续可优化（不在本期范围）

- 灯具档案 SKU 化（卖家给每个 SKU 建一次档案，后续生成秒选）
- 风格预设可扩展（让管理员后台加新预设，覆盖更多细分客群）
- 多灯组合（一盏吊灯 + 几盏壁灯同框出图）
- 季节/时段（春夏秋冬 + 早午晚的氛围对比）
